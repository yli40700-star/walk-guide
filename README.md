# Walk 随身导游

边走边听身边建筑和街区的故事：手机定位你在哪，Claude 写讲解稿，OpenAI 把讲解读给你听。

**打开使用：** https://yli40700-star.github.io/walk-guide/

## 功能

- **讲讲我附近**：读取当前位置，讲 1–2 个身边最值得看的地方，包括原名、建成年份、设计师、后来的变迁和外立面上能亲眼看到的细节。
- **自动讲解**：边走边定位，每走出约 300 米、且距上次至少 4 分钟，自动讲下一段；连续 12 段后暂停。讲过的地方不会重复，还会串联之前讲过的建筑和人物。
- **问导游**：随时追问，比如"这栋楼谁设计的？"，回答会结合你当前的位置。
- **朗读**：讲稿边生成边分段合成语音，第一句很快就能听到。OpenAI 语音不可用时自动改用系统朗读。
- **补充说明和兴趣**：写一句你看到的东西可以纠正定位；可选择建筑、历史、美食、影视取景、拍照机位等方向。

## 使用方法

1. 用手机 Safari 打开上面的网址（可以"分享 → 添加到主屏幕"）。
2. 填入 Anthropic API key（必填）和 OpenAI API key（可选，不填就用系统朗读）。
3. 点"讲讲我附近"，在弹窗里允许定位。
4. 想边走边听就打开"自动讲解"，戴上耳机，屏幕保持亮着。

## 注意

- API key 只保存在页面内存里，不写入浏览器存储，也不在代码里；关掉或刷新页面后需要重新填写。
- 页面需要保持在前台，锁屏或切到其他 App 后定位会停。
- 系统朗读在静音模式下没有声音，请拨开静音开关。
- 讲解由 AI 根据位置推断，具体数字和年份请以权威资料为准。

## 技术

单个 `index.html`，无后端：Geolocation API 定位，Claude API（Sonnet，流式输出）生成讲稿，OpenAI `gpt-4o-mini-tts` 合成语音，Wake Lock API 保持屏幕常亮。
